# AMS 多关键词模型接入点

当前目标为 **AFC03 的 PH1A90SEG324 可编程逻辑**。OCR 放在另一颗 RK3576J 的 NPU，AMS 不随 OCR 迁移到 RK，以保留真实的 PL 模型推理工作。RK 负责短录音播放；麦克风、特征和量化推理目标均在 PH1A90。完整网络与存储能否放下须在模型确定后综合验证。

当前没有模型网络、训练数据或权重，`manifest.example.json` 是交接模板，不能用于推理。AMS 的实际网络结构需按你使用的训练工程确定，不在此处猜测其含义或算子。

目标类别：开始、完成、打印、取消、停止，另设沉默和未知语音。模型输出类别索引与事件 ID 不同，必须按 manifest 显式转换。比如 class_order 的索引 2 才对应 start 事件 1。

建议的数据通路：数字麦克风 → PCM 缓冲 → 与训练一致的特征提取 → 量化网络 → 置信度与连续窗口判定 → 去重 → `keyword_valid/keyword_id`。16 kHz、单声道 PCM16 和 1 秒窗口只是起始建议，不是已经验证的模型参数。

接入时提交：

1. 模型源码、可复现训练命令、类别顺序、数据使用许可与按说话人划分的训练/验证/测试集。
2. 特征参数、归一化、量化位宽、每层 scale/zero-point、算子、张量尺寸、权重及校验值。
3. 软件基准输入/输出向量和定点误差报告。
4. PL 对照仿真、综合 LUT/DSP/ERAM、频率及时序报告。
5. 实际麦克风条件下的识别率、误唤醒/漏检、延迟、打印噪声和提示音回灌测试。

提示音播放可能被麦克风重复识别。量产控制层应加入播放时段屏蔽或可靠回声处理；仿真键盘事件不涉及这些问题，也不能代替测试。未完成上述接入前，RTL 槽位不产生有效分类。
