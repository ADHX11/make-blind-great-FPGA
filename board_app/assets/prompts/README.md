# 提示录音

按以下文件名放入自行录制的短 WAV；未提供录音时只打印提示文字。配置 `prompts.enabled=true` 后通过板载 Linux 的 `aplay` 播放，需先验证 ALSA 声卡和音箱。

| 文件名 | 内容 |
| --- | --- |
| place_book.wav | 开机，请把书籍放置在摄像头下 |
| capturing.wav | 正在拍照识别 |
| ready.wav | 文字已就绪，请说打印 |
| printing.wav | 开始打印 |
| done.wav | 打印完成 |
| error.wav | 出错，请检查并复位 |
| cancelled.wav | 任务已取消 |

播放不阻塞事件循环，新提示会终止旧提示；最长播放 30 秒。真实联调还须实现播放状态到 PL 的通知或回声处理，测试提示音与打印噪声下的误触发；不能把录音中的“打印”误当作用户命令。软件屏蔽不能替代实体急停。当前 v2 协议尚未定义播放状态回传。
