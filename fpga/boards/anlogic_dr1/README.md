# 安路 DR1 板级适配

> 旧方案留档，已不是当前目标。新的默认平台为 [AFC03 / RK3576J + PH1A90](../anlogic_afc03/README.md)。下文只解释原 DR1 规划，不适用于 AFC03 的双芯片接口。

暂定 MLK-F3P-DR1M90G，DR1M90GEG400。`board.json` 记录目标设备和规划值，`pin_plan.csv` 是待填连接表，不是可直接导入的管脚约束。

## 在厂家工具中建立工程

1. 从本板官方资料包取得对应原理图、引脚表、下载器驱动、器件支持包和最小点灯例程。使用能支持该 DR1 器件的安路工具版本；当前资料不足，未猜测具体版本和工程格式。
2. 先独立编译并运行厂家点灯工程，确认芯片完整型号、底板版本、PL 时钟、复位方式和下载链路。
3. 加入 `fpga/rtl/files.f` 所列 SystemVerilog 文件。应用核心顶层为 `blind_printer_core`；它不能直接代替板级封装。
4. 编写 `board_top.sv`：完成时钟/复位、异步输入同步、串口收发、消息解析、UTF-8 解码和麦克风接口，连接应用核心。按对应器件的工具要求补充约束。
5. 首先只使用 LED、UART 和逻辑分析信号，验证状态机和字符流。编译应无未解决端口、无未约束时钟，再查看时序与资源报告。
6. 完成电平、使能极性和独立急停的确认后，才进入运动模块开发和低速单轴调试。

原理图未提供，所以没有编造 PACKAGE_PIN、IOSTANDARD、PLL 原语、AXI 地址或 `.bit` 文件。`board.json` 的 `bitstream_ready` 当前是 false。

## 连接规划

- USB 摄像头接电脑。基础版无需将视频传入 FPGA。
- 数字麦克风接 PL 可用 IO。I2S/PDM 类型需要按实际购买模块选定；板载 AUDIO 不能默认归 PL。
- 初期可用外置 USB-UART 接 PL GPIO；115200 8N1 是通信起步值。底板现有 USB-UART/JTAG 的连线归属必须先查原理图。
- X/Y 用外部 STEP/DIR 驱动器；电磁铁用匹配负载的外部功率级与续流保护。GPIO 只输出逻辑信号。
- 实体急停应切断驱动能源；PL 内的错误状态用于配合停止和报告，不能替代独立断电路径。

板上 PS、NPU 可保留后续扩展，但当前 KWS 的目标是 PL 推理。基础版不需要先安装双系统或移植板载 Linux。
