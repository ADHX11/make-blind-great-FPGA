# AFC03：PH1A90 板级接入

当前默认目标：MLK-AFH03-AFC03-2GB LPDDR4X+32GB EMMC，FPGA 器件 **PH1A90SEG324**，搭配独立 **RK3576J**。型号依据用户提供的安路指南平台 3；最后按实物版本、原理图和厂家例程核对。

[board.json](board.json) 记录已知型号和待定参数；[pin_plan.csv](pin_plan.csv) 是连接规划，**不是管脚约束**。目前 board_top、内核时钟和管脚均未填入，没有生成可烧录文件。

## PL 工程步骤

1. 取得 AFC03 对应的 PH1A90 点灯例程、安路软件/器件支持包、原理图和下载说明；不要把旧 DR1 的器件/约束复制过来。
2. 先编译下载厂家原始例程，确认 JTAG、时钟与复位。指南列有 100 MHz 差分和 25 MHz 单端时钟，最终核心时钟要通过对应输入缓冲/PLL/约束实现。
3. 将 `fpga/rtl/files.f` 中应用核心加入厂家工程。`blind_printer_core` 是核心，不是顶层引脚封装；当前板卡迁移不需要重写其有限英文映射和状态机。
4. 新建真实 board_top：时钟/复位、CDC、厂家板间通信 IP、文本解码、事件/任务缓冲、麦克风前端与页面缓冲。先接 LED/调试，验证无未约束时钟及资源/时序。
5. 在 verified PL IO/FMC 上接数字麦克风和外部驱动逻辑。核对电平、信号归属与使能极性；板载 MIC/音频接口不能未经查图当作 PL 输入。
6. AMS 权重/算子、中文转换、运动模块逐一替换槽位并验收。原核心所有物理输出仍为 0；驱动低有效使能须由板级逻辑正确转换。

## RK 与 PH1A90 通信

指南列出 MIPI 4 lane 和 PCIe 2.0 ×1。先使用厂家已经验证的链路例程，确认谁是 PCIe RC/EP、驱动/设备节点、DMA 与缓冲一致性、MIPI 帧格式以及控制返向通道。没有这些资料前不写虚假的寄存器地址、内存映射或 AXI 连接。

RK Linux 的 transport 工厂将本板驱动转换为 [v2 控制事件](../../../docs/fpga/interfaces.md)。控制文字和图像帧分开处理。第一阶段摄像头直连 RK USB；PL 图像采集/预处理是后续阶段。

实体急停须独立控制驱动能源，PL 配合错误锁定。实际桥接还需实现掉线超时、任务作废及缓冲检查；不能依赖 RK 的 OCR 线程退出才停止机械。

旧 [DR1 配置](../anlogic_dr1/README.md) 只留作历史参考。此板 RK 是外部处理器，不存在可以直接复用的 DR1 片内 PS/PL 地址空间。
